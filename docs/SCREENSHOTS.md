## Privacy processing

The public screenshots were selected and lightly cleaned for repository use. Personal-looking folder labels and internal development-note text were blurred where appropriate. Before replacing any screenshot in the future, check that it does not expose passwords, API keys, account IDs, private notes, names, or notification contents you do not want published.
